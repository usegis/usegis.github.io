# Street data extract

Every California elections office can run one report that answers "which precinct is this address in?" for the whole
county: the street data extract, report `SGMJ001` in most counties' election systems, also called the street index,
street guide or street file. It lists each address with its house number, street, zipcode and precinct. It holds no
voter information: no names, birth dates or party.

Most counties sell it on request today, for $19 to $45 a copy, through a form. Posting it free, and replacing it after
each redraw, serves everyone better.

## For the elections office

- One posting replaces every request: no forms to check, reports to run, files to copy or payments to take.
- It's a report the office already runs, so posting it adds one step after each redraw.
- Fewer calls and emails asking which precinct an address is in.
- Every map and lookup that reads it gives the office's own answer, not a guess from an older map.

## For residents

- Any website or app can show voters their precinct and districts from the county's own records.
- The answer is right for every address, including new homes and rural roads that maps miss.
- It's current after each redraw, before ballots go out.

## For everyone else

Cities, schools, special districts, journalists, researchers and campaigns of every party get the same file, at the
same time, at no cost.

## How to post it

1. Run the street data extract countywide, one line per address rather than address ranges.
2. Save it as a CSV or text file, or load it as a table on the county's GIS server.
3. Post it at a link that stays the same, with the date of the lines it reflects.
4. Replace it after each redraw.

## Free on request

Under Elections Code §12263, the precinct map is already free on request. The street data extract carries the same
lines, address by address, and should be free too.
