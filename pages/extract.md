# Street data extract

Every California elections office can run one report that answers "which precinct is this address in?" for the whole
county: the street data extract, report `SGMJ001` in most counties' election systems, also called the street index,
street guide or street file. It lists each address with its house number, street, zipcode and precinct. It holds no
voter information: no names, birth dates or party. Although some counties sell this data, others post it as a free
download. The staff time involved in processing each request is a net loss, so this information should simply be
available for free.

Posted once, the same file reaches cities, schools, special districts, journalists, researchers and campaigns of every
party, at the same time and at no cost.

## For the elections office

One posting replaces every request, with no forms to check, reports to run, files to copy or payments to take. It's a
report the office already runs, so posting it adds one step after each redraw. Fewer people call or email to ask which
precinct an address is in, and every map and lookup that reads the file gives the office's own answer, not a guess
from an older map.

## For residents

Any website or app can show voters their precinct and districts from the county's own records. The answer is right for
every address, including new homes and rural roads that maps miss, and it's current after each redraw, before ballots
go out.

## How to post it

Run the street data extract countywide, with one line per address rather than address ranges. Save it as a CSV or text
file, or load it as a table on the county's GIS server, and post it at a link that stays the same, with the date of the
lines it reflects. Replace it after each redraw.

## Free on request

Under Elections Code §12263, the precinct map is already free on request. But a map alone can't say which precinct an
address is in, so without a free street data extract as well, it isn't especially useful.
